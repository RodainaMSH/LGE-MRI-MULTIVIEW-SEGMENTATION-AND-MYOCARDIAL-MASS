## How to read this

Every model is scored under **three regimes** (rows **① / ② / ③** — the 3 ways DSC is computed), all full **4-view**, broken down **per-view → per-class** with the aggregate metrics on the right. Two multi-level tables (`nnunet/per_class_nested.py`): **A = the multi-architecture ENSEMBLE** (the submission model — soft-voting across encoders, the exhaustive-search winner) and **A2 = all single models** (one encoder per row, what A ensembles over). Same columns/metric → A and A2 are directly comparable.

- **① Ours (OOF-40)** — our strict metric: per-volume Dice, **skip** classes empty in both pred & GT (`unified_eval/compute_dsc.py`), over OOF 5-fold CV on the 40 train patients. **The trusted decision metric.**
- **② Paper (OOF-40)** — the paper/challenge metric (`qutaiping/CMR_multi_baseline 2D_seg/metrics.py dice_score`): per-**slice** 2D, `smooth=1e-6` so a class **empty in both → 1.0** (this is the "how no-scar-on-SAX is handled" difference); inflates focal scar. Same 40 OOF patients (`nnunet/score_their_metric.py`).
- **③ Competition (7-val)** — the **paper metric on the official 7 validation patients** (41–47 + RAS 81–94), 5-fold ens **+pp** (`nnunet/prelim_eval.py`). 🐞 Bug-fixed 2026-06-09 (was our metric → now theirs). Extremely noisy (mass over **n=5** nonzero-scar patients) — context, not a decision metric.

Columns — the table is **multi-level** (each view header spans its per-class sub-columns; an aggregate block sits on the right):
- **Per-view → per-class DSC** — under each view `SAX`/`2CH`/`4CH`, its labelled classes **① LVcav · ② LVmyo · ③ scar · ④ RVcav** (the numbers = the segmentation **label indices** 1–4), then that view's **_DSC_** (fg-mean). `2CH` has no RVcav. **RAS** = the separate shared **RAS expert** (`Dataset004_LGERAS`, held-out 81–94, leakage-safe; single class **① RA**, **our 0.8921 / their 0.8866** — the **XL cardiac warm-start** (ImageNet→cardiac-LGE→RAS, fold_0; adopted 2026-06-10, replaced the 0.870 from-scratch expert). *Identical for every model*, the generalist only does SAX/2CH/4CH).
- **Overall DSC** = mean of the 4 per-view DSCs (full 4-view) = the headline number. ⚠️ each view _DSC_ is **patient-cell-pooled** (weights classes by #patients), so it is **not** the plain average of its 4 class cells — scar, scored on fewer patients, is weighted less.
- **scar** = label-3 Dice over SAX/2CH/4CH (RAS has none) — the **discriminator** (lowest cell, widest model spread; everything else is near a tight ceiling).
- **vPCC / RAE↓** = SAX scar-**mass** quality (voxel-Pearson ↑, rel-abs-err ↓); ① & ② share them (same OOF mass), ③ differs (7-val set).
- **a** = OOF-refit scale-only mass calibration (same value in all regimes, leakage-safe).
- **Mass** = MassScore `0.5·max(0,vPCC) + 0.5/(1+RAE)` — the 0.3-weighted half of Task2, **submitted as a SEPARATE file** (`mass_predictions.json`) from the masks. ① & ② share it (OOF); ⚠️ ③ is over **n=5** scar patients → noisy/lucky. **⭐ Best honest-OOF Mass = DenseNet-264 (0.620, vPCC 0.650, LOO-robust), NOT XL (0.585)** → best submission = **XL mask (best DSC) + DenseNet-264 `mass_predictions.json`** (Task2 ① **~0.708** / ② **~0.714** with the warm-start RAS, beats either alone).
- **Task2** = `0.7·Overall-DSC + 0.3·Mass` — vs Codabench leader 0.68; **decision metric stays ① OOF**.

## A) ⭐ Multi-architecture ENSEMBLE — the submission model (NEW 2026-06-11)

**What this table tests.** Every row in **A2** is a *single* model (one encoder). **A** is the **soft-voting ensemble**: run several *different-architecture* models, **average their softmax probability maps, then argmax**. Cross-architecture errors are more decorrelated than cross-fold, so the consensus **beats any single model on DSC** — but only the *right* members help. We ran an **exhaustive search over all 2,047 subsets of the 11 tested 5-fold models** (`nnunet/ens_exhaustive.py`), scored every combo on **OOF-40** *and* the **held-out 7-val (41–47)** (`nnunet/val7_compare.py`), and the winner is the **6-model soft-average below**. Same 3 regimes / metric / columns as A2 → rows are **directly comparable**. Generated by adding the ensemble run (`ENS_best6` + 7-val cand `cand_ensbest6`) to `nnunet/per_class_nested.py`.

- **Winner's members:** EffNetV2-XL · DenseNet-264 · EffNetV2-L · ScarTversky · PlainConv-100ep · **SPADE-aug DenseNet** (`spade_dn264` — the GAN-aug model, useless *solo* but a valuable *decorrelated* member). **Equal weight** (learned/upweighting was shown to be an OOF mirage). RAS = the shared warm-start expert (0.892), same as A2.
- **DSC peaks at ~6 members, then DECLINES** — adding the weak models (SAM/RIN/Hiera) drags it; the **all-11 ensemble is the WORST big ensemble** (① 0.697). More ≠ better.

## Footnotes / honest caveats

1. **Which mass each regime uses:** ① and ② Task2 use the **40-pt OOF** mass (vPCC≈0.50–0.58) — honest, leakage-safe, what we trust. ③ Task2 uses the **7-val** mass (vPCC over 7, RAE over n=5 nonzero) — that's why ③ Task2 reads ~0.70 (a much smaller, noisier patient set, not a real improvement). The old "~0.718 estimate" was an even more optimistic 7-pt mass (vPCC≈0.807) — discard it.
2. **Mass decouples from DSC:** in principle graft the best-mass source onto the best-DSC masks. On OOF, V2-XL has both the best DSC *and* the best mass (vPCC 0.576), so no cross-grafting gain — V2-XL is the all-round lead.
3. **Metric reconciliation:** our strict scar (0.41 OOF) reads ≈ **0.58** under their per-slice metric; most of the apparent gap to the paper's 0.608 is metric convention, not model quality (`metric-reconciliation.md`).
4. **Not comparable to the paper's 0.75:** their seg was ~150 annotated cases, single 7:1:2 held-out (not OOF), institutional LGE (not CMR-MULTI). Their "Ours" = a gated 2-stage SAX cascade (scar 60.83 = a GT-prompted-class number), *not* the public ResUNet++ baseline (scar 26.13).
5. **Decision metric = OOF over the 40 train.** The blind 39-pt LGE test set is the real selection target but unlabeled locally. 🚫 R&D only — no Codabench submission without the professor's OK.
